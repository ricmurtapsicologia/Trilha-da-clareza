# Trilha da Clareza

Uma jornada entre pensamentos, emoções e escolhas.

**Estado:** implantação técnica do MVP 0.1.0 em andamento. **Não homologado para uso assistencial.**

Projeto independente de psicoeducação interativa para adultos, baseado em fundamentos da TCC. Não realiza diagnóstico, avaliação de risco nem atendimento de emergência.

Políticas do projeto:
- Sem cadastro e sem dados de pacientes no código.
- Sem armazenamento automático de respostas.
- Não compartilhar com pacientes antes da revisão clínica, segurança, acessibilidade e testes de implantação.
- Publicação separada da homologação assistencial.
